## **🌐 HTTP REST Endpoints (`/chat`):**

- `POST /chat/messages` - Create new message
- `GET /chat/conversations` - Get user's conversations
- `GET /chat/conversations/:id/messages` - Get conversation messages
- `GET /chat/conversations/:id/messages/last/:count` - Get last N messages
- `POST /chat/conversations/:id/join` - Join a conversation
- `GET /chat/conversations/:id/participants` - Get participants
- `GET /chat/dashboard/stats` - Dashboard statistics

## **⚡ WebSocket Events:**

- `join_room` - Join a conversation room
- `leave_room` - Leave a conversation room
- `send_message` - Send a new message
- `typing_start/stop` - Typing indicators
- `get_messages` - Retrieve messages via WebSocket
- `share_robot_message` - Share robot responses (placeholder)
